# Thakur — Free Educational Library

An online library built for **educational purposes**, offering free access to open-access academic materials and public-domain story books.

## About

Thakur is a personal, non-commercial project created to make legally free educational content easily accessible in one place. All materials hosted or linked here are either:

- **Open-access resources** published by open universities and made freely available for reading and download, or
- **Public-domain works** (story books and similar texts) that are no longer under copyright protection or were released for free public use.

No copyrighted or paid content is hosted on this platform.

## Access

To keep usage within the intended community and prevent unrestricted public scraping, access to the library is limited to registered users:

- Users create a free account using a **username and password**.
- Authentication is handled via **Firebase (Firestore)**.
- Only signed-in users can view or download materials.

## Features

- 📚 Browse and search available PDFs
- 🔐 Simple username/password authentication
- ⬇️ Download or read materials online
- 🎓 Focused entirely on open-access and public-domain content

## Purpose

This project is maintained strictly for **educational, non-commercial use**. It is intended to help learners access legally free study materials and literature without barriers.

## Disclaimer

All content made available through this platform is either open-access (freely published by originating institutions) or in the public domain. If you believe any material listed here is included in error or infringes on a copyright, please reach out so it can be reviewed and removed promptly.
